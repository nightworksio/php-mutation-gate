# The mutation-gate mark

The mark is the MG monogram "Passage": one continuous stroke on a 40 by 29
grid, 3 units wide, with round caps and joins. [`mark.svg`](mark.svg) is the
master. It draws in `currentColor`, so it takes the colour of the text around
it when it is placed inline. [`mark-light.svg`](mark-light.svg) (ink `#16191c`)
and [`mark-dark.svg`](mark-dark.svg) (ink `#eef1f3`) are the same path with a
fixed colour, for places that show an SVG as an image and cannot pass a colour
in, such as the README's header. The mark is used as drawn: it is not
recoloured, redrawn, stretched or combined with other shapes.
